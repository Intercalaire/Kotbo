KOTBO - Widget stats staff pour Android (KWGT)
================================================

KWGT est une app gratuite de widgets personnalisables (Play Store : "KWGT Kustom
Widget Maker"). Elle sait interroger une URL et extraire des valeurs par
regex - pas besoin d'app native ni de rooter le téléphone.

Ton URL de données (remplace le token si tu le régénères depuis le dashboard,
page Widget) :

  https://kotbo.fr/api/public/widget-data?token=TON_TOKEN

(Si tu utilises une instance self-hosted, remplace "kotbo.fr" par le domaine
de ton dashboard.)

INSTALLATION
------------
1. Installe KWGT depuis le Play Store.
2. Appui long sur l'écran d'accueil → Widgets → KWGT → dépose un widget vierge.
3. Ouvre l'éditeur KWGT, ajoute un composant "Texte" pour chaque statistique
   que tu veux afficher (niveau, messages, vocal, staff score, nom du
   serveur...).
4. Pour chaque composant Texte, dans le champ "Texte", colle une des formules
   ci-dessous (remplace TON_TOKEN par ton token).
5. Dans les réglages du composant, choisis un intervalle de rafraîchissement
   (KWGT met en cache le résultat de wg() sur cette durée) - 15 à 30 minutes
   est raisonnable.

FORMULES (à coller dans le champ "Texte" d'un composant KWGT)
---------------------------------------------------------------

Niveau :
  $rgx(wg(https://kotbo.fr/api/public/widget-data?token=TON_TOKEN)|"level":\s*(\d+)|1)$

Messages :
  $rgx(wg(https://kotbo.fr/api/public/widget-data?token=TON_TOKEN)|"messageCount":\s*(\d+)|1)$

Vocal (minutes) :
  $rgx(wg(https://kotbo.fr/api/public/widget-data?token=TON_TOKEN)|"voiceMinutes":\s*(\d+)|1)$

Staff score :
  $rgx(wg(https://kotbo.fr/api/public/widget-data?token=TON_TOKEN)|"staffScore":\s*(\d+)|1)$

Rang staff :
  $rgx(wg(https://kotbo.fr/api/public/widget-data?token=TON_TOKEN)|"staffRank":\s*"([^"]*)"|1)$

Nom du serveur :
  $rgx(wg(https://kotbo.fr/api/public/widget-data?token=TON_TOKEN)|"name":\s*"([^"]*)"|1)$

Nombre de membres :
  $rgx(wg(https://kotbo.fr/api/public/widget-data?token=TON_TOKEN)|"memberCount":\s*(\d+)|1)$

REMARQUES
---------
- KWGT effectue une requête réseau par formule wg() ; si tu utilises la même
  URL dans plusieurs composants avec le même intervalle de rafraîchissement,
  KWGT réutilise généralement le cache au lieu de refaire l'appel.
- Le token est une clé secrète en lecture seule : elle ne permet ni de te
  connecter au dashboard, ni de modifier quoi que ce soit. Tu peux la
  régénérer à tout moment depuis la page Widget si tu penses qu'elle a fuité.
- Pour une icône du serveur, KWGT propose un composant "Image réseau" avec la
  même URL et le chemin JSON "iconUrl" - utilise la formule :
    $wg(https://kotbo.fr/api/public/widget-data?token=TON_TOKEN)$
  puis configure le composant Image en mode "URL depuis texte" si ta version
  de KWGT le permet, ou utilise directement l'icône du serveur Discord.
